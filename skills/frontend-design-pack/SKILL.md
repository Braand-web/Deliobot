# Frontend design pack

Five of the most-installed design skills. `<SKILLS>` below is this skill's folder. Read the one that fits:

| The work | Read |
|---|---|
| A new interface or page that must not look generic | `<SKILLS>/frontend-design/SKILL.md` |
| Polish an existing UI: hierarchy, spacing, states, details | `<SKILLS>/impeccable/SKILL.md` |
| Choose a style, palette, fonts and UX rules for a product type | `<SKILLS>/ui-ux-pro-max/SKILL.md` (its search script needs Python 3) |
| Animation, interaction and the small details that feel right | `<SKILLS>/emil-design-eng/SKILL.md` |
| Review a page against web interface guidelines | `<SKILLS>/web-design-guidelines/SKILL.md` |

## In Deliobot

Show the page while you work (`show_html`, or the browser tools on the local preview) and take a phone-size and a
desktop screenshot before saying it is done. Use the person's brand (brand-kit skill) when they have one. Pictures come
from Deliobot's media tools or the person, never from a site you do not have rights to.
